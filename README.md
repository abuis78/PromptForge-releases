# PromptForge

**AI Prompt Composer for macOS** — build, structure and send prompts to multiple AIs at once.

[**⬇ Download latest release**](https://github.com/abuis78/PromptForge-releases/releases/latest)

</div>

---

## What is PromptForge?

PromptForge is a native macOS app that helps you write better prompts faster. Instead of typing from scratch every time, you assemble prompts from reusable building blocks — tiles, skills, sticky instructions — and send them to one or multiple AIs simultaneously.

---

## Features

| | |
|---|---|
| 🧩 **Tile System** | Click reusable prompt blocks (Persona, Context, Format, Constraints…) — text inserts at cursor |
| 🤖 **Skills** | Tag reusable instructions per AI provider (Claude, GPT, Gemini, Ollama) |
| 📁 **Projects** | Organise prompts by project, each with its own draft and history |
| ⚡ **Multi-Send** | Send one prompt to multiple AIs in parallel — compare responses side by side |
| 🌐 **Browser targets** | Open Claude.ai, ChatGPT, Gemini, Perplexity, Phind in one click |
| 📎 **Sketch to Prompt** | Insert a structured sketch-analysis prompt, then attach your whiteboard image in the AI chat |
| 🎙 **Voice input** | Transcribe speech to text (local Whisper model, fully offline) |
| ✨ **Prompt optimiser** | Improve your prompt with a local or cloud LLM |
| 📌 **Sticky instructions** | Text always appended to every prompt |
| 🕐 **History** | Full prompt history, filterable by project, with bookmarks |
| 🌍 **Multilingual** | German · English · Français · Español |

## Installation

1. Download `PromptForge-vX.X.X.dmg` from [Releases](https://github.com/abuis78/PromptForge-releases/releases/latest)
2. Open the DMG and drag **PromptForge.app** into your Applications folder
3. Launch PromptForge — macOS Gatekeeper is satisfied (app is notarised by Apple)

> **Requirements:** macOS 14 Sonoma or later · Apple Silicon or Intel
