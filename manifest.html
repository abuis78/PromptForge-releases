PromptForge // AI Prompt Composer

Prompts bauen. Strukturieren. An mehrere AIs gleichzeitig senden.

Die meisten Prompts werden einmal getippt und vergessen. PromptForge ändert das — Bausteine einmal anlegen, immer wieder kombinieren, direkt in jede AI senden.

Kein Browser-Plugin. Keine Cloud. Kein Abo. Eine native macOS-App.

// core features

🧩
Tile System
Klickbare Prompt-Bausteine. Text landet direkt am Cursor.
⚡
Multi-Send
Ein Prompt — alle AIs gleichzeitig. Antworten nebeneinander.
🤖
Skills
Wiederverwendbare Anweisungen, je AI-Anbieter getaggt.
📁
Projects
Eigener Entwurf + History pro Projekt. Kontext bleibt erhalten.
🎙
Voice Input
Lokales Whisper-Modell. Offline. Kein API-Call.
📎
Sketch → Prompt
Whiteboard-Analyse-Prompt auf Knopfdruck. Bild selbst hochladen.
✨
Prompt Optimiser
Prompt via LLM verbessern — lokal oder Cloud-API.
📌
Sticky Instructions
Text der immer angehängt wird. Einmal setzen, nie vergessen.
